| 约 10,000 台注册设备 | ¥6,000–20,000 | ¥5,000–30,000 | ¥11,000–50,000 |

这些区间假设 API 模型而非自建 GPU，并且需要根据日活和消息量重新计算。云厂商活动价、地域、带宽和高可用级别可能造成数倍差异。

## 模型费用计算

```text
月输入费用 = 月输入 token / 1,000,000 × 输入单价
月输出费用 = 月输出 token / 1,000,000 × 输出单价
月模型费用 = 所有路由层的输入费用 + 输出费用 + 媒体/工具调用费用
```

示例假设：1,000 台注册设备、日活 20%、每台活跃设备每天 100 条客户消息，即每月约 60 万条。若低成本模型全量初筛，高质量模型只处理 10%–15%，并严格裁剪上下文，模型预算可先按约 ¥1,000–4,000/月准备。此示例不是用量承诺。

## 采购前必须填写的参数

- 注册设备、平均和峰值在线设备、日活比例。
- 每台活跃设备每天的消息数、消息 token、图片/语音比例。
- 低成本和高质量模型的调用比例、重试率、缓存命中率。
- 数据保留期、备份周期、可用区数量、出口带宽。
- 人工客服数量、管理后台并发和监控日志量。

## 降本顺序

1. 规则过滤和检索裁剪，减少无效 token。
2. 低成本模型分类，高质量模型按置信度升级。
3. 非实时任务使用每日批处理和缓存。
4. 调整数据与日志保留期。
5. 在有稳定容量数据后再购买包年资源或考虑自托管模型。
