- 建立所有 AI 共用的规范来源。

- Markdown 规范、状态、任务、架构和成本文件。
- AI 工具入口文件。
- `.gitignore` 安全默认值。

## 不在范围

- 旧 PHP 源码、生成的 Protobuf 文件或客户数据导入。
- Go、PHP、Python 生产代码。
- 服务器部署、数据库创建或模型 API 调用。
- 对现有业务进行功能修改。
