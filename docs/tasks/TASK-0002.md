# TASK-0002：旧源码安全与迁移审计

状态：已完成
负责人：Codex
开始日期：2026-08-19
最后更新：2026-08-19

## 目标

以本机仓库外的旧 PHP 服务端为只读输入，形成可复现、已脱敏的模块、依赖、许可证、配置、秘密风险和协议资产报告，为 `.proto` 恢复及 Go 网关实现提供可信输入。

## 输入边界

- 旧源码保留在仓库外，仅作只读分析。
- 不复制客户数据、密钥、数据库、日志、运行时文件或敏感二进制到公开仓库。
- 报告只记录文件相对路径、风险类别和处置建议，不记录秘密值。
- 对第三方 `vendor/` 只做依赖与许可证盘点，不复制其源代码。

## 已发现

- 旧服务包含 ThinkPHP、Workerman/Swoole、Redis 队列和 Google Protobuf。
- 根目录包含 `composer.json`、`.example.env`、`config/`、`app/`、`extend/` 和完整 `vendor/`。
- `extend/` 下存在名称明确表示敏感内容的二进制文件，禁止读取内容或上传。
- 原始 `.proto` 尚未发现，但 `extend/lib/protobuf` 下有生成消息类和 `GPBMetadata`。
