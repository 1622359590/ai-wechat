# TASK-0004：Go 协议网关最小闭环与测试部署

状态：进行中
负责人：Codex
开始日期：2026-08-19
最后更新：2026-08-19

## 背景

TASK-0003 已提交五类最小 Protobuf 3 协议和 15 个公开安全合成帧，并验证 Go/旧 PHP wire 兼容。当前需要把这些资产接入可运行的 Go TCP 网关，但真实鉴权后端、测试设备和生产 TLS 尚未进入实现范围。

## 目标

- 建立安全默认值的 Go TCP 网关。
- 跑通帧读取、协议解码、鉴权状态、心跳、好友消息和可选发送任务链路。
- 使用已有 15 个 fixture 做回放回归。
- 提供健康检查、优雅关闭和最小容器部署。
- 完成本机 Docker staging；远程目标可用时再部署到测试服务器。

## 不在范围

- 真实客户设备、真实 credential、聊天数据或生产流量。
- PostgreSQL、Redis、PHP HTTP 适配、AI、记忆和知识图谱。
- 公网生产 TLS、域名、负载均衡和高可用。
- 自动接受任意设备的测试后门。

## 验收条件

- [ ] Go 根 module 和内嵌最小 schema 可重复构建。
- [ ] frame codec 覆盖半包、粘包、零长度、超限和截断。
- [ ] protocol codec 回放 15 个 fixture 并严格校验 MsgType/Any 映射。
- [ ] 未鉴权连接只能提交设备鉴权；默认鉴权器拒绝全部连接。
- [ ] 注入测试鉴权器后可处理心跳、好友消息并编码发送任务。
- [ ] TCP server 支持 deadline、连接错误隔离和优雅关闭。
- [ ] `/livez`、`/readyz` 行为有自动测试。
- [ ] Docker 镜像非 root，Compose 默认只绑定本机回环地址。
- [ ] 本机 staging 部署和健康检查通过，或准确记录环境阻断。
- [ ] 独立审查无未解决 Critical/Important，公开安全门通过。

## 风险

- 动态描述符适合最小阶段，但高吞吐前需要 benchmark 决定是否生成强类型代码。
- 原协议最大帧长未知；1 MiB 只是安全起点，必须由 TASK-0005 样本调整。
- 默认拒绝鉴权意味着 staging 只验证服务与协议基础，不声称真实设备已接通。
- 当前没有远程服务器 SSH 目标，不能凭空完成远程部署。
