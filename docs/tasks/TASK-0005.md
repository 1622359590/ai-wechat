# TASK-0005：远程 staging 与真实设备接入准备

状态：进行中
负责人：Codex
开始日期：2026-08-19
最后更新：2026-08-20

## 背景

TASK-0004 已实现并在本机验证 Go 协议网关最小闭环。用户随后提供一台已有宝塔面板的测试服务器并明确要求在服务器运行；服务器已有网站和数据库，不能覆盖或中断现有业务。

## 目标

- 将与合并提交 `443432e` 对应的 Linux AMD64 网关部署到远程安全 staging。
- 保持 deny-all 鉴权和回环地址限定，未完成 TLS/访问控制前不暴露公网 TCP。
- 验证产物一致性、容器健康、安全参数、资源限制和异常连接隔离。
- 为后续受控鉴权和真实测试设备接入保留明确边界。

## 不在范围

- 自动修改现有网站、数据库、PHP 服务或业务端口。
- 在没有真实鉴权后端和 TLS 的情况下开放公网设备入口。
- 执行全系统安全更新、重启现有业务或修改宝塔账号。
- 提交服务器 IP、面板入口、账号、密码、Cookie 或其他基础设施秘密。

## 验收条件

- [x] 确认服务器系统、架构、资源和现有业务边界。
- [x] 安装并启动 Docker，不中断已有网站和数据库。
- [x] 上传 Linux AMD64 静态二进制并核对 SHA-256。
- [x] 使用独立目录、镜像和 Compose 项目运行网关。
- [x] 容器为非 root、只读、无 capabilities、启用 `no-new-privileges`，并应用 CPU/内存/PID 限额。
- [x] 容器为 `running/healthy`，live/ready 为 200，异常帧后不重启。
- [x] 18080/19090 仅监听远程主机回环地址。
- [ ] 接入受控测试鉴权器，不使用 accept-all 后门。
- [ ] 配置 TLS 或受控专网入口及防火墙白名单。
- [ ] 连接真实测试设备验证鉴权、心跳、断线和消息收发。
