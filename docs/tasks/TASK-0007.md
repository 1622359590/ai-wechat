# TASK-0007：设备管理 Web 后台

状态：已完成（隔离远程候选已验证，等待用户创建真实管理员并配置域名）

## 背景

`TASK-0006` 已提供独立 PostgreSQL 设备注册表和本机管理 CLI，但正式设备库从空库开始，运营人员需要自行添加、停用、恢复和设置设备有效期。用户明确选择管理员账号加密码登录，并自行完成域名解析；后台不得绑定固定域名。

## 目标

- 提供单管理员起步、可扩展为多管理员的 Web 后台。
- 支持添加设备、查看状态、停用、恢复和设置到期时间。
- 支持管理员登录、退出和修改密码。
- 后台服务仅监听服务器回环地址，通过任意 HTTPS 域名反向代理访问。
- 复用现有设备领域服务，数据库仍只保存 Credential 的 HMAC 指纹。
- 管理操作形成不包含 Credential、Token、完整源 IP 或自由文本秘密的审计记录。

## 不在范围

- 将域名、证书或公网地址写死在代码或仓库配置中。
- 忘记密码邮件、短信、第三方 OAuth、复杂角色权限和租户管理。
- 查看或恢复设备 Credential 明文。
- 删除设备记录；首版以停用代替删除。
- 在后台中直接操作聊天记录、联系人、模型、记忆或知识图谱。
- 在首个真实设备录入并验证前替换现网 `19090`。

## 验收条件

- [x] 未登录请求不能读取或修改任何设备数据。
- [x] 密码仅保存为带独立盐的 Argon2id 哈希，日志和响应不包含密码。
- [x] 登录具备统一失败响应、限流、安全 Session、CSRF 防护和安全 Cookie。
- [x] 可添加设备编号、标签、状态和到期时间；只持久化 HMAC 指纹。
- [x] 可查看内部 UUID、标签、状态、到期时间和最后成功鉴权时间，不展示 Credential 或指纹。
- [x] 可停用、恢复和修改到期时间；停用在线设备会触发现有断线通知。
- [x] 管理员可修改密码，现有其他 Session 随即失效。
- [x] 管理操作具有固定动作和原因代码的审计记录。
- [x] 服务默认仅监听回环地址，PostgreSQL 不暴露公网，仓库示例不含真实域名或秘密。
- [x] 单元、PostgreSQL 集成、HTTP 安全、容器 smoke、竞态检测和静态检查全部通过。
- [x] 在服务器隔离部署后台，通过回环入口模拟可信 HTTPS 代理完成登录和合成设备操作验证；最终域名和证书由用户自行配置。

## 风险

- 后台一旦通过公网域名开放，会成为高价值入口；没有 HTTPS 时必须拒绝部署。
- 旧 APK 的设备编号不是强秘密；后台控制只能防止未登记设备连接，不能消除已知编号被冒充的协议风险。
- 管理员忘记密码时首版只能通过服务器本机受控命令重置，不能通过公开接口找回。
- 当前服务器资源有限，管理服务必须保持小型依赖、低并发和明确资源上限。
